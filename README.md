# Leather-Hub

**Ambur Leather Works** — Mobile-First Direct-to-Consumer (D2C) E-Commerce Web App for authentic, handcrafted bovine leather goods from Ambur, Tamil Nadu (India's premier leather craftsmanship hub).

---

## 🏷️ Brand Identity & Core Offerings
- **Origin**: Ambur, Tamil Nadu (PIN 635802).
- **Core SKUs**:
  - **Classic Bi-Fold Coin Wallet**: Oil pull-up bovine full-grain leather (₹899).
  - **Minimalist Slim RFID Cardholder**: Waxed Crazy Horse finish (₹499).
  - **Reversible Formal / Casual Belt**: Solid 3.8mm strap with 360° rotating brass buckle (₹999).
  - **Ambur Heritage 2-in-1 Executive Gift Box**: Wallet + reversible belt in keepsake box with matching personalization (₹1,699).
- **Unique Selling Points**:
  - 100% Genuine Ambur Bovine Leather (No synthetic/bonded fillers).
  - Heirloom Patina Longevity (5-Year Guarantee).
  - Complimentary Custom Initials/Name Embossing (Gold Foil & Blind Deboss).
  - Zero-Cost WhatsApp Order Automation with Instant UPI Confirmation.

---

## ⚡ Tech Stack
- **Framework**: Next.js 16 (App Router, Turbopack, React 19, TypeScript)
- **Styling**: Tailwind CSS v4 with custom brand tokens (Deep Saddle `#1A1412`, Ambur Tan `#C89D66`, Rich Cream `#FDFBF7`, Heritage Brass `#B38F4D`)
- **Icons**: Lucide React
- **State Management**: Zustand with persistent client hydration
- **PWA**: Mobile web app manifest, touch swipe carousel, double-tap 2.5x macro zoom, native bottom-sheet personalization, and persistent bottom navigation bar.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (LTS v24 recommended)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/Adithya0805/Leather-Hub.git
cd Leather-Hub

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

### Production Build
```bash
npm run build
npm run start
```
