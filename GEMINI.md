# Dino Leathers — Project Instructions

## Overview
Dino Leathers (`https://dinoleathers.in`): E-commerce platform for authentic bovine leather goods from Ambur, Tamil Nadu.

## Framework & Stack
- Next.js 16 (App Router)
- React 19
- Tailwind CSS v4
- Supabase (PostgreSQL)
- Framer Motion

## CLI Usage
Run Gemini CLI in this workspace:
- `npx gemini` (interactive)
- `npm run gemini`
- `npx gemini --prompt "your instructions"` (non-interactive / headless)
